# 🌌 Orbitly

Orbitly is a demo astronomy exploration website designed to make exploring the universe simple, visual, and engaging.

## ✨ Features

- Bento grid layout
- Responsive design
- Astronomy-themed UI
- Smooth animations and transitions
- Hover interactions
- Scroll reveal animations
- Featured planets and space facts
- Upcoming astronomy events
- Community and newsletter sections

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## 🎨 Design Focus

This project focuses mainly on:

- UI/UX design
- Responsive layouts
- Bento grid design
- CSS animations
- Micro-interactions
- Clean and modern visual design
